# Legal and privacy

## Scope

FamilyTime Save Manager manages save files that you created and own. It reads them, copies them
into backups, and restores backups you select. It does not include, extract, distribute or modify
any proprietary game code, assets, audio, models or other copyrighted content.

## No DRM or access-control bypass

The application does not bypass DRM, licensing checks, encryption or access controls. It does not
patch executables, inject code or unlock content. It only reads files the game already writes in
your user profile or game folder.

## No game files in this repository

This repository contains only original source code, tests, documentation and screenshots of the
save manager itself. No game binaries, assemblies, assets or extracted content are included, and
the release packages contain only the save manager.

## Trademarks

"Family Time" and any related names belong to their respective owners. This project is unofficial
and is not affiliated with, endorsed by, or sponsored by the game's developer or publisher.

## Privacy

- No network connections, telemetry, analytics or crash reporting.
- No accounts, sign-in or cloud storage.
- Backups, history, settings, profiles and logs are stored only under
  `%LOCALAPPDATA%\FamilyTimeSaveManager` on your PC.
- Save paths and file names appear in the local logs and history; nothing is transmitted.

## Your responsibility

Keep your own copies of important saves. This software is provided under the MIT license, without
warranty. Test a restore with a copy you can afford to lose before relying on it for important
progress.
